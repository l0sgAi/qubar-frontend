# @提及搜索列表新增用户邮箱显示

## 背景结论
- 下拉列表由两个结构几乎相同的组件渲染:`src/components/MentionTrigger.vue:18-33`(发帖编辑器内联版)和 `src/components/MentionPicker.vue:35-49`(评论区按钮版),两处都要改,保持一致。
- **数据层无需任何改动**:`useUserSearch.js` 原样透传 `/user/search` 返回的用户对象,`email` 字段已存在(搜索页 `UserList.vue` 已在渲染它)。
- 面板因 NPopover teleport 到 body,样式必须写全局 `src/assets/main.css` 的 `.mention-*` 系列(536-665 行附近)。

## 排版方案:两行布局(邮箱在 username 正下方)
理由:面板窄(240-260px),单行内联会让邮箱严重截断失去"唯一标识"作用;两行布局与搜索页 UserList 的现有邮箱展示模式一致,展示空间最充裕。同屏候选数从约 6 行减至 4-5 行,可接受。

## 改动清单

### 1. `src/components/MentionTrigger.vue`(模板 18-33 行)
将 username 与 email 包进纵向容器,位于头像之后、角色徽标之前:
```vue
<NAvatar ...>...</NAvatar>
<div class="mention-user-info">
  <span class="mention-user-name">{{ user.username }}</span>
  <span v-if="user.email" class="mention-user-email">{{ user.email }}</span>
</div>
<span class="mention-role" ...>...</span>
```
email 行加 `v-if="user.email"` 兜底(接口可能无邮箱,避免空行)。

### 2. `src/components/MentionPicker.vue`(模板 35-49 行)
同样改动,结构保持与 MentionTrigger 一致。

### 3. `src/assets/main.css`(`.mention-*` 系列旁)
- 新增 `.mention-user-info`:`flex: 1; min-width: 0; display: flex; flex-direction: column;`(min-width:0 保证内部 ellipsis 生效)
- 新增 `.mention-user-email`:`font-size: 11px; color: 弱化色(用 var(--text-tertiary) 或既有 rgba 弱化模式); ellipsis 单行截断`
- 调整 `.mention-user-name` 适配纵向容器(保持 13px 与 ellipsis)
- 面板加宽容纳邮箱:`.mention-picker` 240px → 280px;`.mention-suggest` 260px → 300px
- 严格复用 main.css 既有设计 token,不引入新色值;实现时先加载 `frontend-style-constraints` skill 确认约束

### 4. `src/components/MentionTrigger.vue`(脚本 89 行)
`PANEL_H = 200` → 约 `240`:行高变高后首帧翻转定位的估高更准(仅估算值,nextTick 仍会量真实高度)。

### 5. 附带小清理(可选,一行)
`CreatePost.vue:164` 残留的 `import MentionPicker`(模板已不用,上次提交漏删)一并删除。

修复 AdminAgents 页 tab 切换时「卡片被挤在未伸展容器中」的视觉问题

## 根因
- `NTabs animated`（AdminAgents.vue:64）使 `.n-tabs-pane-wrapper` overflow:hidden 且切入瞬间按「当时内容」测高钉住 max-height 过渡 0.2s；
- circles pane 默认 `display-directive="if"` → 每次切换重新挂载 ManagedCircleList → onMounted 当场请求、先渲染骨架卡；
- 请求返回骨架换成真卡片（更高）时 wrapper 还钉着骨架高度的 max-height 并裁切内容，0.2s 后才瞬间弹开 → 出现「卡片挤在未伸展容器里」。

## 改动
1. src/views/AdminAgents.vue：两个 NTabPane 加 `display-directive="show"`。pane 页面加载即挂载常驻（v-show 切换），circles 数据预取与全局 agents 并行；每次切换仅显隐翻转，Naive 测得真实卡片高度，动画全程无内容交换 → 无裁切无跳变，且切换不再重复请求/无骨架闪烁。
2. src/components/ManagedCircleList.vue：骨架卡补描述行、统计行占位，使骨架高度≈真实卡片高度，兜底「慢网下用户抢先点 tab」的边缘场景。

## 不做
- 不移除 animated（保留滑动动画）；不自写高度动画。

## 验证
npm run dev，管理员账号来回切换 tab、圈子搜索/翻页，确认切换无裁切/跳变；样式改动遵循 frontend-style-constraints 规范。

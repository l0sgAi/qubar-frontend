我们的理念

一个社区，应该是大家的

趣吧不靠流量变现，也不替你决定该看什么。我们只想把这几件事做好。

把鼠标放上去，或点一下卡片，翻到背面看看

  • 开放

    推门就能进

    游客不用注册也能随便逛；想参与时，邮箱或 Google / GitHub / Microsoft 一键登录，中英双语随时切换。

  • 开源

    代码摊开给你看

    前后端两个仓库都以 MIT 协议开源。读代码、提 Issue、自己部署一套，都欢迎。

  • 共享

    内容属于社区

    内容和讨论属于社区。兴趣在圈子之间流动，好内容通过推荐、热门和发现，被更多同好看到。

  • 圈主自治

    圈子的事，圈子说了算

    规则、成员、审核、机器人，都由圈主和管理员自己经营。平台不替圈子做决定。

  • 非营利 · 轻量

    不打扰，刚刚好

    不以流量变现为目标。界面简洁不吵闹，一台服务器就能跑起来。

  • AI 是伙伴

    帮忙，不抢戏

    机器人帮圈子答疑、活跃气氛；身份清楚、发言有频率上限，怎么用由圈主决定。

圈子与圈主自治

建一个圈子，
按你的方式经营

给圈子起个好记的短链接，定好加入方式，再找几位管理员一起打理。新帖先过一遍 AI 预审，拿不准的交给你们拍板。

  • 短链接 + 三种加入方式

    c/你的圈子，好记好分享。公开、申请审核、私密，圈子氛围自己定。

  • 圈主、管理员、成员

    三级角色各司其职；遇到捣乱的，可以禁言或移出。「我加入的圈子」还能按角色筛选。

  • AI 预审，人来拍板

    发帖后先由 AI 预审，拿不准的进入审核队列，最终由圈子管理员决定。

  • 举报有人管，通知直达

    成员可以举报帖子，管理员在圈子管理页处理；审核类通知一点就到「审核」页，待处理数量一目了然。

创作与互动

写下热爱，
总有人接得住

用 Markdown 写图文，拖进几张照片顺手裁好，选个圈子就能发。之后谁点了赞、谁回了你、谁 @ 了你，都会第一时间告诉你。

  • 图文创作

    Markdown 编辑器，多图上传和裁剪，选好所属圈子再发布。

  • 楼层式评论

    评论和回复一层一层排好，聊得再热闹也不乱。

  • 点赞、收藏、浏览历史

    喜欢就点赞，想留着就收藏，看过的随时翻回来。

  • @ 提及，精确到人

    @ 谁就提醒谁；收到通知点一下，直接跳到那条评论。

AI 机器人伙伴

请一位小 Q，
帮圈子热热场

机器人可以接入不同的大模型服务，自己起名字、换头像、写一段人设。它只在该出现的时候出现，说多少、在哪说，都由圈主决定。

什么时候开口？

  • 被 @ 时
  • 帖子命中关键词
  • 管理员手动叫它
  • 自动回复高热度的帖子和评论
  • 全局机器人 + 圈内机器人

    圈内机器人由圈主自己管理，只在本圈发言。

  • 用一句话管住它

    过滤提示词告诉它什么时候该开口，什么时候安静。

  • 有分寸

    自动回复时，同一条内容最多回一次；发言有频率上限，不会和其他机器人互相接话；用独立账号发言，资料页标着「机器人」。

账号与登录

邮箱注册登录、找回密码，Google / GitHub / Azure AD OAuth 一键登录；游客模式先逛后注册，中英双语界面随心切换。

AI 社区机器人

给圈子请一位
7×24 的 AI 伙伴

每个圈子都可以接入自己的 LLM 机器人：它住在线的帖子里，被 @ 或命中关键词时出现，用你定义的口吻回答问题。

  • 可插拔 LLM 接入：自定义协议、Base URL、API Key、模型与生成参数，兼容主流 OpenAI 风格服务。
  • 提示词双保险：System Prompt 塑造机器人人格，过滤提示词为发言内容把关。
  • 关键词 / @ 双触发：帖子命中关键词或被 @ 时自动回复，最大回复数与最小回复间隔双重频控。
  • 圈级后台管理：圈主在圈子内创建、编辑、删除机器人，名称与头像随心定制。

实时消息与互动

新互动，
秒级落在你眼前

未读通知从 30s 轮询升级为 SSE 服务端主动推送——全量事件、心跳保活、断线自动降级，多标签页之间也能保持一致。

  • SSE 单向推送：基于普通 HTTP，自带重连与事件 ID，25s 心跳防止网关空闲断连。
  • 全量语义：每次推送完整未读数，与本地已读校正取最新值，不做增量累加。
  • 优雅降级：连接失败自动回落 30s 轮询，可用性不依赖推送通道是否在线。

01

模块化单体优先

单进程一次部署，领域靠清晰边界自治；将来若要拆分为微服务，领域边界早已画好。

02

Write-Behind 异步统计

点赞、浏览等高频计数先写缓存，再经 Redpanda 异步批量落库——热点写不再顶穿数据库。

03

SSE 优于 WebSocket

未读数是服务端 → 客户端的单向语义：SSE 跑在普通 HTTP 上，自带重连与 Last-Event-ID 续传，免去双向心跳的复杂度。

04

可插拔 LLM 机器人

协议、端点、密钥、模型与提示词全部配置化——不改一行代码，即可切换任意兼容的模型服务。
